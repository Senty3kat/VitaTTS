# Vita TTS

Быстрый синтезатор речи для PS Vita (хомбрю) для музыкальных экспериментов и живых выступлений: ввёл фразу — нажал — она звучит.

- Движки: **Pico** (SVOX, EN US/UK), **eSpeak-NG** (RU, JA, EN), **SAM** (C64, EN и ретро-RU).
- История из 5 последних фраз, регулировки скорости, высоты тона и громкости.
- **Слоговый режим**: фраза режется на слоги, слоги играются по кнопке или касанию задней панели с привязкой к темпу (BPM, квантайз).
- Сборка VPK — GitHub Actions (вкладка Actions → артефакт `VitaTTS-vpk`), установка через VitaShell.

Подробности: `docs/HISTORY.md`, правила работы и решения — `CLAUDE.md`. Проверка кода без VitaSDK: `make -C host check-all`.

Лицензии: Pico — Apache 2.0, eSpeak-NG — GPL-3.0 (при раздаче VPK нужно соблюдать GPL), SAM — «брошенное ПО».
